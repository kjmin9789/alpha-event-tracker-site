campaign_id에 연결할 프로모션 이름이에요.

기간을 바꾸면 해당 기간의 데이터가 필요해요.

집계 데이터

GA에서 조회한 이벤트 발생 수를 불러와요. 데이터는 이 파일 안에서만 처리해요.

데이터 입력·불러오기

행마다 event_name, campaign_id, placement_key, event_count가 필요해요. 배너별 집계에는 banner_id(클릭은 id도 가능)를 추가해요. 전체 조회를 확인한 경우에만 completeViews / completeClicks를 true로 설정해요.

조회 기준

노출: view__promotion_banner
클릭: click_promotion_banner
집계: 캠페인 × 위치별 이벤트 수
카피 비교: 배너 ID별 집계가 추가로 필요해요.
사용자 수가 아닌 발생 횟수 기준이에요.

서로 다른 배너, 같은 카피

같은 카피의 배너 ID를 하나의 세트로 묶어주세요.

배너 ID규격카피 세트

카피별 전체 성과

전체 위치 합산 · CTR = 클릭 합계 ÷ 노출 합계 × 100

위치·노출 대상의 구성이 달라 카피 자체의 효과를 단정할 수는 없어요.

위치별 성과

클릭률 = 클릭 수 ÷ 노출 수 × 100 · 같은 위치 안에서 비교해요.

위치별 카피 비교

관측 클릭률 순위이며 통계적 유의성을 판정하지 않아요. 노출 대상·기간·기기·배너 규격 차이가 결과에 영향을 줄 수 있어요.
